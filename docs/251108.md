## 디자인 계획 (Design Plan)

### 페이지 구조 (Page Structure)
- **라우트**: `/2025/[locale]/awardees` (동적 로케일 지원)
- **컴포넌트**: `page.tsx` 파일 생성
- **네비게이션**: 탑바와 사이드바에 "수상자 / Awardees" 메뉴 추가

### 레이아웃 컨셉 (Layout Concept)
- **카드 기반 그리드**: 카드 디자인으로 팀 정보 표시 (클릭 불가, 표시용)
- **카드 내용**:
  - 상단: 팀 이미지 (4:5 비율, 둥근 모서리)
  - 팀 이름 (볼드, 큰 폰트)
  - 프로젝트 제목 (중간 폰트)
  - 수상 등급 (색상 강조, 예: 금색/은색/동색)
  - 참가자 목록 (로케일에 따라 KR/EN)
  - "View Team" 버튼 (외부 팀 페이지 링크)
  - 글로벌 배지: `isGlobal: true`인 경우 `/images/awardees/badge.png` 이미지 추가

### 글로벌 배지 배치 (Global Badge Placement)
- 카드 우상단에 배지 이미지 배치
- 크기: 40x40px 정도
- 글로벌 팀만 표시

### 모바일 반응형 (Mobile Responsiveness)
- **데스크톱**: 3-4열 그리드 (`grid-template-columns: repeat(auto-fit, minmax(300px, 1fr))`)
- **태블릿**: 2열 그리드
- **모바일**: 1열 그리드, 카드 패딩 조정
- 이미지와 텍스트 크기: `clamp()` 사용으로 유동적 조정

### 한국어/영어 분리 (Korean/English Separation)
- **제목**: "수상자" / "Awardees"
- **참가자**: `participantsKR` / `participantsEN` 배열 사용
- **팀 이름/프로젝트**: 데이터에 이미 포함 (이미 영어 위주)
- **수상 등급**: 영어 그대로 사용 (1ST PLACE 등)

### 사이드바 네비게이션 (Sidebar Navigation)
- 팀 이름 목록 + 번호 (01-12)
- 클릭 시 해당 카드로 스크롤 (`scrollTo` with offset 70px)
- 로고 스케일: 1.5x (다른 페이지와 동일)

### 타이포그래피 및 스타일 (Typography & Styling)
- **팀 이름**: RethinkSans-ExtraBold, 24px, #000000
- **프로젝트 제목**: RethinkSans-Medium, 18px, #000000
- **수상 등급**: RethinkSans-Bold, 16px, 색상 코드별 (1ST: #FFD700, 2ND: #C0C0C0, etc.)
- **참가자**: RethinkSans-Regular, 14px, #575757, 콤마로 구분
- **링크 버튼**: 파란색 배경, 흰색 텍스트, 호버 효과

### 기술 구현 세부사항 (Technical Implementation Details)
- **이미지 최적화**: Next.js Image 컴포넌트, priority for first 2 cards
- **카드 호버**: 그림자 증가, 약간 위로 이동
- **링크 처리**: `target="_blank"`로 새 탭 열기
- **데이터 처리**: JSON 데이터를 컴포넌트 내 배열로 정의 (외부 수정 없이)
- **반응형 이미지**: `sizes` 속성으로 뷰포트별 최적화

### 예상 카드 높이 (Estimated Card Height)
- 각 카드: 약 450-500px (이미지 300px + 텍스트)
- 그리드 갭: 2rem
- 모바일에서 카드 높이 조정으로 스크롤 최적화

### 글로벌 배지 디자인 (Global Badge Design)
- 위치: 카드 우상단, 이미지 위에 오버레이
- 스타일: 둥근 배경, 약간 투명도
- 크기: 32x32px (모바일) ~ 40x40px (데스크톱)
