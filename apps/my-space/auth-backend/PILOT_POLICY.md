# Pilot 정책 요약 — 2026-10-09

확정 정책/코드 구조의 기준은 POLICIES_AND_ARCHITECTURE.md, 실행/환경변수 기준은 LOCAL_SETUP.md, 상세 DB/API 목표는 CODEX_HANDOFF.md다.

- 제공자가 검증한 소셜 이메일과 이미 승인된 적격 참가 기록 1명만 유일 매치할 때 자동 연결. 직접 입력한 NASA 이메일은 인증 증거가 아니다.
- 불일치: NASA 이메일 입력 → 소유 인증 → 운영팀 등록 대조·계정 연결 승인. 소유 인증·등록 자격·허브 승인·보호자 확인·연락 동의는 별도다.
- 참가자와 팀 모집은 seeking/paused/completed. seeking만 새 탐색 목록·관심 수신을 허용하며 기존 활성 대화는 유지한다.
- 같은 행사·실제 두 참가자 간 최대 3개 대화, 활성 1개. 시작자 3회·답변자 2회·교대로 총 5개, 각 50자.
- 마지막 메시지 이후 5×24시간 미응답이면 자동 종료. 종료 기록·메시지·전체 대화 사용 횟수는 유지. 답변이 오면 기한 재계산, 종료 후 답변은 불가.
- 팀 카드 이메일은 확인된 오너에게 전달하고 오너의 ‘대원에게 이메일 받기’를 사용한다. 별도 팀 동의 없음. 오너 미연결/최신 동의 미확인은 기본 거부.
- 다른 대원 카드에서는 보낸 사람의 역할에 따라 수신자의 owner/peer 동의를 확인. 발송자는 자신의 이메일 공개에 별도 동의. 이후 답장은 허브 밖에서 진행한다.
- 본문·외부 답장을 저장하지 않고 발송 메타데이터만 기록한다. 실제 발송 시 최신 동의와 실제 수신자를 서버에서 재검사한다.
- 공식 생성팀 갱신은 허브 모집글·모집 상태·소유자 연결을 덮어쓰지 않으며 수집 실패는 삭제로 해석하지 않는다.
- 원본 등록자료는 읽기 전용. 확인된 팀 소속 전환 시 참가자의 찾기 상태를 completed로 변경하고 팀 모집 상태와 분리한다.

현재 비공개 Site는 화면/검토 흐름이다. 로컬 인증·운영자 승인 서버는 구현됐으나 외부 서비스·실제 자료 연결은 미완료다. 실제 관심·프로필·모집·연락 API는 남아 있다. review-store.js의 예시 데이터/localStorage는 운영 DB가 아니다.

검사: `npm run check`, `npm test`, `npm run test:roles`, `npm run test:server`. 실제 모바일 실화면 및 두 계정/두 기기의 서버 연결 검증은 미완료다.
